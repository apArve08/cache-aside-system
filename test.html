Submitted Project: Glasshouse

A flight recorder for coding AI agents — captures what an agent actually did during a session, never its hidden reasoning, and links every event into a tamper-evident cryptographic chain you can replay and verify offline.

What it does
  • Records observable actions only: file reads/writes, commands, output, test runs
  • Every event hash-chains to its predecessor — SHA256(prev_hash + timestamp + payload)
  • Editing, deleting, or reordering any event breaks the chain from that point forward
  • Replays as one self-contained ~29KB HTML file — no backend, no network, opens from file://
Agent support
  • Codex CLI — working, via a wrapper around codex exec --json
  • Claude Code — working, via native settings.json hooks (PreToolUse / PostToolUse / Stop)
  • Gemini CLI, OpenCode, custom agents — planned, via an AgentAdapter contract
  • Format is agent-neutral: any recorder emitting a valid chain replays in the same viewer

Security model
No hidden reasoning, no private prompts, no secrets or raw env vars are ever recorded. Replay is client-side, so session contents stay on the reviewer's machine unless deliberately published.
